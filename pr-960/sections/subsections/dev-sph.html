Evaluation kernels#

SPH evaluation in physical space.

The smoothing kernel \(W_h\) is radial and normalized in physical space (sph_radial_kernels) and pulled back to the logical unit cube as a 0-form,

\[\hat W_h(\boldsymbol\eta, \boldsymbol\eta') = W_h\big(|F(\boldsymbol\eta) - F(\boldsymbol\eta')|\big)\,, \qquad \hat\rho_h(\boldsymbol\eta) = \sum_j c_j\, \hat W_h(\boldsymbol\eta, \boldsymbol\eta_j)\,.\]

The physical marker positions \(\mathbf x_j = F(\boldsymbol\eta_j)\) are stored in the marker array (columns x_idx, x_idx + 1, x_idx + 2, filled by physical_positions()). The physical distance vector between an evaluation point and marker \(j\) is

\[\mathbf r = P_\textnormal{res} \Big( \mathbf x - \mathbf x_j - \sum_{i\,\textnormal{periodic}} k_i\, \mathbf P_i \Big)\,, \qquad k_i = \textnormal{round}(\eta_i - \eta_{j,i})\,,\]

with the period vectors \(\mathbf P_i = F(\boldsymbol\eta + \mathbf e_i) - F(\boldsymbol\eta)\) of the periodic directions (constant, checked at setup) and the projection \(P_\textnormal{res}\) onto the directions resolved by the kernel (the identity for 3D kernels).

struphy.pic.sph_eval_kernels.physical_positions(args_markers: MarkerArguments, args_domain: DomainArguments, holes: bool[:], x_idx: int)[source]#

Store the physical positions \(\mathbf x_p = F(\boldsymbol\eta_p)\) of all markers (including ghost particles) in markers[x_idx:x_idx + 3, :].

Mirrored ghost particles of wall boundary conditions sit outside the unit cube (at \(-\eta\) or \(2 - \eta\)). Their physical position is the first-order extrapolation from the foot point \(\boldsymbol\eta_w\) on the wall (the clamped position),

\[\mathbf x_g = F(\boldsymbol\eta_f) + DF(\boldsymbol\eta_w)\, (\boldsymbol\eta_g - \boldsymbol\eta_f)\,,\]

where \(\boldsymbol\eta_f\) is the folded position (the marker that was mirrored). This is the exact mirror image for planar walls whose logical normal column of \(DF\) is orthogonal to the wall (e.g. Cuboid); otherwise it is an oblique reflection.

Parameters:

  • args_markers (MarkerArguments) – Marker arguments.

  • args_domain (DomainArguments) – Arguments of the mapping.

  • holes (bool[:]) – True for holes in the marker array.

  • x_idx (int) – First of the three marker columns for the physical position.

Kernel setup#

Setup of the physical SPH smoothing kernel of a ParticlesSPH species.

The kernel \(W_h\) is radial and normalized in physical space (sph_radial_kernels). The neighbour search uses the sorting boxes of the logical unit cube: the sum for a marker runs over the 27 boxes around it. The kernel width \(h\) is therefore limited by

\[h_\max = \min_{i\ \textnormal{resolved}}\ \frac{1}{n_i\, \max_{\boldsymbol\eta} \big\| P_\textnormal{res} (DF^{-1})_{i,:}(\boldsymbol\eta)^\top \big\|}\,,\]

since a physical displacement \(\Delta\mathbf x\) changes \(\eta_i\) by \((DF^{-1}\Delta\mathbf x)_i \leq \|(DF^{-1})_{i,:}\|\, |\Delta\mathbf x|\), which must not exceed the box width \(1/n_i\). The maximum is taken over a sampling grid finer than the boxes.

Directions with a single sorting box are not resolved by the kernel (1D and 2D kernels). The mapping must then be affine and constant in these directions, orthogonal to the resolved ones; distances are projected onto the resolved directions (\(P_\textnormal{res}\)) and the kernel is divided by the physical measure \(A_\perp\) of the unresolved directions.

Smoothing kernels#

Radial SPH smoothing kernels in physical space.

Each kernel is a function of the physical distance \(r = |\mathbf x - \mathbf x'|\) with compact support of radius \(h\), normalized in \(d = 1, 2, 3\) dimensions of physical space,

\[W_h(r) = \frac{\sigma_d}{h^d}\, w(q)\,, \qquad q = \frac rh \in [0, 1]\,, \qquad \int_{\mathbb R^d} W_h(|\mathbf x|)\, \textrm d \mathbf x = 1\,.\]

Kernel ids (kernel):

  • 1, "gaussian": \(w(q) = e^{-9 q^2}\) (standard deviation \(h/(3\sqrt 2)\)), truncated at \(q = 1\) and renormalized over the ball;

  • 2, "wendland_c2": \(w(q) = (1 - q)^3 (1 + 3q)\) for \(d = 1\), \((1 - q)^4 (1 + 4q)\) for \(d = 2, 3\);

  • 3, "cubic_spline" (M4): \(w(q) = 1 - 6q^2 + 6q^3\) for \(q \leq 1/2\), \(2(1 - q)^3\) for \(1/2 < q \leq 1\).

The normalization constants \(\sigma_d\) were checked by numerical integration (see the unit tests).
