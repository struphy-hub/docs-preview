class struphy.feec.psydac_derham.DiscreteDerham(V0: TensorFemSpace, V1: VectorFemSpace, V2: VectorFemSpace, V3: TensorFemSpace)[source]#

Bases: object

Discrete 3D de Rham sequence built from four FE spaces.

Used internally by Derham (via Derham.init_derham) to create the base FE spaces and derivative operators before boundary, polar, and projector augmentations are added.

The sequence is represented as

V0 --grad--> V1 --curl--> V2 --div--> V3

where V0 is an H1-conforming scalar space, V1 an Hcurl vector space, V2 an Hdiv vector space, and V3 an L2 scalar space.

The auxiliary space (H^1)^3 for vector fields is also built for projection and polar extraction purposes, but it is not part of the proper de Rham sequence.

Moreover, the 1D FEM spaces (serial, not distributed) in each direction are built from the corresponding 3D spaces, and stored as attributes for building Kronecker matrices.

Parameters:

  • V0 (TensorFemSpace) – First space of the de Rham sequence : H1 space

  • V1 (VectorFemSpace) – Second space of the de Rham sequence : Hcurl space

  • V2 (VectorFemSpace) – Third space of the de Rham sequence : Hdiv space

  • V3 (TensorFemSpace) – Fourth space of the de Rham sequence : L2 space

Notes

On construction, differential operators are created and attached to the input spaces as convenience attributes:

  • V0.grad and V0.diff

  • V1.curl and V1.diff

  • V2.div and V2.diff

class struphy.feec.psydac_derham.SplineAttributes1D(femspace: TensorFemSpace | VectorFemSpace, nquads: tuple[int, int, int], nquads_proj: tuple[int, int, int], polar_splines: bool = False, local_projectors: bool = False)[source]#

Bases: object

Container for 1D spline metadata extracted from a 3D FE space.

This helper precomputes and stores per-direction information needed by projection operators, quadrature-based assembly, and spline evaluation kernels. It supports both scalar (TensorFemSpace) and vector-valued (VectorFemSpace) spaces.

Parameters:

  • femspace (TensorFemSpace | VectorFemSpace) – Finite-element space from which the 1D spline information is derived.

  • nquads (tuple[int, int, int]) – Number of quadrature points in each logical direction (eta_1, eta_2, eta_3) for numerical integration grids.

  • nquads_proj (tuple[int, int, int]) – Number of quadrature points in each logical direction used to build projection point/weight sets.

  • polar_splines (bool, default=False) – Polar spline regularity flag. False selects standard tensor-product splines, while True enables C1 polar splines (including the optional shift of points near eta_1 = 0 where required).

  • local_projectors (bool, default=False) – If True, also computes quasi-interpolation point/weight grids used by local commuting projectors.

Notes

Data layout depends on the input space type:

  • scalar space: each attribute is indexed by direction;

  • vector space: each attribute is indexed by component, then direction.

The class stores:

  • spline descriptors (number of basis functions, spline kind),

  • projection grids (points, weights, sub-interval markers),

  • optional local-projector grids,

  • quadrature grids (points, weights, spans, basis values).

class struphy.feec.psydac_derham.Derham(grid: TensorProductGrid, options: DerhamOptions, comm: SerialComm | None = None, domain: Domain | None = None, *, domain_decomposition: DomainDecomposition | None = None)[source]#

Bases: object

High-level discrete de Rham complex on the 3D logical unit cube.

The class builds a tensor-product base complex through DiscreteDerham and augments it with optional boundary enforcement, optional C1 polar extraction operators, and commuting projectors. It also stores convenient metadata (1D spline attributes, decomposition helpers, index arrays) used by initialization, evaluation, and kernel interfaces.

Parameters:

  • grid (TensorProductGrid) – The FEEC grid.

  • options (DerhamOptions) – The options for building the discrete de Rham sequence, including spline degrees, boundary conditions, quadrature options, polar spline options, and projector options.

  • comm (Intracomm) – MPI communicator (sub_comm if clones are used).

  • domain (Domain, optional) – The Struphy domain object for evaluating the mapping F : [0, 1]^3 –> R^3 and the corresponding metric coefficients.

  • domain_decomposition (DomainDecomposition, optional) – Prescribed MPI decomposition of the elements, e.g. fine_derham.domain_decomposition.coarsen(...) for an aligned multigrid level. Must match grid.num_elements and the periodicity from options.bcs, and be built on comm. If None (default), it is computed from comm and grid.mpi_dims_mask.

Notes

The underlying base sequence is

V0 --grad--> V1 --curl--> V2 --div--> V3.

An auxiliary H1vec FEM space is also built for vector-field projection and polar extraction machinery.

Initializes a callable spline function with a method for assigning initial conditions.

The spline function of the coefficients \(s_{ijk}\) (coeffs) in the space \(V^\alpha_h\) with the basis functions \(\Lambda^\alpha_{ijk}\) (\(\alpha = 0, 3\)), on the logical domain, is

\[S_h(\boldsymbol \eta) = \sum_{ijk} s_{ijk}\, \Lambda^\alpha_{ijk}(\boldsymbol \eta)\,,\]

and, for the vector-valued spaces (\(\alpha = 1, 2, v\)), component-wise

\[S_{h,\mu}(\boldsymbol \eta) = \sum_{ijk} s_{\mu, ijk}\, \Lambda^\alpha_{\mu, ijk}(\boldsymbol \eta)\,, \qquad \mu = 1, 2, 3\,.\]

Calling the spline function returns these logical components (no push-forward to the physical domain). This notation \(S_h\) is used throughout Struphy for a spline function, e.g. evaluated at the marker positions \(S_h(\boldsymbol \eta_p)\).

Parameters:

  • name (str) – Field’s key to be used for instance when saving to hdf5 file.

  • space_id (str) – Space identifier for the field (“H1”, “Hcurl”, “Hdiv”, “L2” or “H1vec”).

  • derham (struphy.feec.psydac_derham.Derham) – Discrete Derham complex.

  • backgrounds (FieldsBackground | list) – For the initial condition.

  • perturbations (Perturbation | list) – For the initial condition.

  • domain (Domain) – Mapping for pullback/transform of initial condition.

  • equil (FluidEquilibrium) – Fluid background used for inital condition.

  • projection (str) – Projection of the initial condition into the spline space: “commuting” (the commuting projector of the Derham, default) or “L2” (the L2-orthogonal projection, L2Projector, needs domain).

Obtain local projection point sets and weights in one grid direction for the quasi-interpolation method. The quasi-interpolation points are \(\nu - \mu +p\) equidistant points \(\{ x^i_j \}_{0 \leq j < \nu - \mu +p}\) in the sub-interval \(Q = [\eta_\mu , \eta_\nu]\) given by:

begin{itemize}

item Clamped: .. math:

Q = \left\{\begin{array}{lr}
[\eta_p = 0, \eta_{p+1}], & i = 0 \,,\\
{[\eta_p = 0, \eta_{p+i}]}, & 0 < i < p-1\,,\\
{[\eta_{i+1}, \eta_{i+p}]}, & p-1 \leq i \leq \hat{n}_N - p\,,\\
{[\eta_{i+1}, \eta_{\hat{n}_N} = 1]}, &  \hat{n}_N - p < i < \hat{n}_N -1\,,\\
{[\eta_{\hat{n}_N -1}, \eta_{\hat{n}_N} = 1]}, & i = \hat{n}_N -1 \,.
\end{array} \; \right .

item Periodic: .. math:

Q = [\eta_{i + 1}, \eta_{i + p}] \:\:\:\:\: \forall \:\: i.

end{itemize}

Which are allways a subset of \(\{-(p-1)h,-(p-1)h + \frac{h}{2}, ..., 1-h - \frac{h}{2},1-h \}\) for the periodic case.

Parameters:

  • space_1d (SplineSpace) – Psydac object for uni-variate spline space.

  • polar_shift (bool) – Whether to shift the first interpolation point away from 0.0 by 1e-5 (needed only in eta_1 and for polar domains).

Returns:

  • pts (2D float array) – Quadrature points (or quasi-interpolation points for interpolation) in format (ii, iq) = (interval, quadrature point).

  • wts (2D float array) – Quadrature weights (or 1’s for interpolation) in format (ii, iq) = (interval, quadrature point).

class struphy.feec.mass.WeightedAverageProjection(derham: Derham | None = None, *args, **kwargs)[source]#

Bases: LinearOperator

Projection onto functions that are constant in the given directions, orthogonal with respect to a symmetric positive (semi-)definite operator \(\mathbb S\) on the 0-form coefficients:

\[\Pi_{\mathbb S} = \mathbb E \, (\mathbb E^\top \mathbb S \, \mathbb E)^{-1} \, \mathbb E^\top \mathbb S \,,\]

where \(\mathbb E\) embeds the coefficients of the remaining directions as constant along the averaged ones (\(\mathbb E^\top\) sums over the averaged directions). For a weighted mass matrix \(\mathbb S\), \(\Pi_{\mathbb S} \phi\) is the spline in the remaining directions closest to \(\phi\) in the weighted \(L^2\) norm, i.e. the weighted average (e.g. the flux-surface average with the volume element \(\sqrt g\) for \(\mathbb M^0\)). Then

\[\mathbb S (\mathbb I - \Pi_{\mathbb S}) = \mathbb S - \mathbb S \mathbb E \, (\mathbb E^\top \mathbb S \, \mathbb E)^{-1} \, \mathbb E^\top \mathbb S\]

is symmetric. If the weight of \(\mathbb S\) does not depend on the averaged directions, \(\Pi_{\mathbb S}\) is the plain average of AverageOperator. If all three directions are averaged, \(\mathbb E\) is the vector of ones and the reduced matrix is the scalar \(\mathbb 1^\top \mathbb S \, \mathbb 1\) (the weighted mean over the whole domain).

The reduced matrix \(\mathbb E^\top \mathbb S \, \mathbb E\) (on the remaining directions) is assembled once by probing \(\mathbb S\) with colored vectors and factorized on every process; one application costs one application of \(\mathbb S\) and a sparse solve.

Class for assembling basis projection operators in 3d.

A basis projection operator \(\mathcal P: \mathbb R^{N_\alpha} \to \mathbb R^{N_\beta}\) is defined by the matrix

\[\mathcal{P}_{(\mu, ijk),(\nu, mno)} = \hat{\Pi}^\beta_{\mu, ijk} \left( A_{\mu,\nu}\,\Lambda^{\alpha}_{\nu, mno} \right)\,,\]

where the weight fuction \(A\) is a tensor of rank 0, 1 or 2, depending on domain and co-domain of the operator, and \(\Lambda^\alpha_{\nu, mno}\) is the B-spline basis function with tensor-product index \(mno\) of the \(\nu\)-th component in the space \(V^\alpha_h\). The operator \(\hat \Pi^\beta: V^\beta \to \mathbb R^{N_\beta}\) is a commuting projector from the continuous space into the space of coefficients; it can be decomposed into computation of degrees of freedom (DOFs) \(\sigma^\beta: V^\beta \to \mathbb R^{N_\beta}\) and inversion of the inter/-histopolation matrix \(\mathcal (I^\beta)^{-1}: \mathbb R^{N_\beta} \to \mathbb R^{N_\beta}\):

\[\hat \Pi^\beta = (I^\beta)^{-1} \sigma^\beta\,.\]

\(I^\beta\) is usually a Kronecker product and thus fast to invert; this inversion is performed when calling the dot-product of the BasisProjectionOperator. The DOFs are precomputed and stored in StencilVector format, because the local support of each \(\Lambda^\alpha_{\nu, mno}\).

Finally, extraction and boundary operators can be applied to the DOFs, \(B_P * P * \sigma * E_V^T * B_V^T\).

i.e. \(\mathbb G^T \mathbb M_1 \mathbb G + \sigma \mathbb M_0\), \(\mathbb C^T \mathbb M_2 \mathbb C + \sigma \mathbb M_1\) and \(\mathbb D^T \mathbb M_3 \mathbb D + \sigma \mathbb M_2\).

The matrix in the middle (mid, default \(\mathbb M_{k+1}\)) and the stabilization (stab, default \(\mathbb M_k\)) can be other weighted mass operators with the same domain and codomain (or sums and multiples of them), e.g. mid="M1gyro" and stab="M0ad_withT"; stab="Id" is the identity. For the gradient, stab_average replaces the stabilization \(\mathbb S\) by \(\mathbb S (\mathbb I - \mathbb A)\), where \(\mathbb A\) is the \(\mathbb S\)-weighted average over the given directions (WeightedAverageProjection), as in the adiabatic gyrokinetic Poisson equation.

With unit weights (the operator on the logical cube), the mass matrices are block-diagonal Kronecker products of 1d mass matrices \(M_d\), and each diagonal block of \(A\) is a sum of Kronecker products,

\[A_{cc} \approx \sum_{d \in N_c} M_1 \otimes \dots \otimes S_d \otimes \dots \otimes M_3 + \sigma \, M_1 \otimes M_2 \otimes M_3 \,,\]

with the 1d stiffness matrices \(S_d = \mathbb d_d^T M^D_d \mathbb d_d\) in the directions \(N_c\) in which component c is differentiated (its B-spline directions). These blocks are inverted exactly by fast diagonalization (Lynch, Rice and Thomas 1964; for spline stiffness matrices see Sangalli and Tani 2016, in the References below; implemented in KroneckerSumSolver): with the generalized eigendecompositions \(S_d U_d = M_d U_d \Lambda_d\), \(U_d^T M_d U_d = I\), and \(U = U_1 \otimes U_2 \otimes U_3\), the block is \(A_{cc} = U^{-T} D \, U^{-1}\) with the diagonal matrix \(D = U^T A_{cc} U\) (sums of Kronecker products of the \(\Lambda_d\) and identities, plus \(\sigma\)), hence \(A_{cc}^{-1} = U D^{-1} U^T\), at the cost of a few 1d matrix products per direction. For the gradient this is the exact inverse on the logical cube. For curl and div, the off-diagonal blocks are neglected (block Jacobi, \(P_{BJ}\)).

Block Jacobi overestimates \(A\) on the kernel of \(\mathbb d\) (gradients for curl, curls for div), where \(A = \sigma \mathbb M_k\). With kernel_correction (default, needs \(\sigma > 0\)), the preconditioner is

\[P = P_{BJ} + \sigma^{-1} \, \mathbb d_- \, P_- \, \mathbb d_-^T \,,\]

where \(\mathbb d_-\) is the previous derivative (\(\mathbb G\) for curl, \(\mathbb C\) for div) and \(P_-\) approximates the inverse of \(\mathbb d_-^T \mathbb M_k \mathbb d_-\) (the grad preconditioner for curl, the curl block Jacobi for div). On the range of \(\mathbb d_-^T\) the kernel of \(\mathbb d_-\) does not matter, since \(\mathbb G^T \mathbb C^T = 0\).

The geometry is included with weights="average" (default) and by diagonal scaling (default, see KroneckerPreconditioner). For the weights, fast diagonalization needs the same 1d mass matrix in each direction for all terms, so the weights \(w\) of the mass matrices are approximated by one common separable shape \(\prod_d \phi_d(\eta_d)\) (mean 1; \(\phi_d\) is the mean over the other directions, averaged over the diagonal blocks of \(\mathbb M_{k+1}\)), times the mean of the weight of each term (the block of \(\mathbb M_{k+1}\) for the stiffness term of each direction, the block of \(\mathbb M_k\) for the mass term). This is exact e.g. for constant but anisotropic weights. A block of mid with zero mean (e.g. the parallel direction of a perpendicular operator) gives no stiffness term in that direction; its 1d stiffness still defines the eigenbasis of the fast diagonalization.

The averaged stabilization \(\mathbb S (\mathbb I - \mathbb A)\) is approximated by \(\bar s \, (M_1 \otimes M_2 \otimes M_3 - F_1 \otimes F_2 \otimes F_3)\) with \(F_d = c_d c_d^T / (\mathbb 1^T c_d)\), \(c_d = M_d \mathbb 1\), in the averaged directions (\(F_d = M_d\) otherwise). In directions with \(S_d \mathbb 1 = 0\) (periodic or without essential boundary conditions) the constants are an eigenvector of the fast diagonalization and this term is exact in its eigenbasis (it removes the averaged modes). The identity (stab="Id") is replaced by its diagonal in that eigenbasis; its average is Euclidean, i.e. \(M_d\) is replaced by the identity and \(c_d = \mathbb 1\).

General operators. Instead of a derivative, derivative can be a KroneckerBlockOperator \(\mathbb L\) (blocks that are sums of Kronecker products of 1d matrices), e.g. \(\mathbb L = \mathbb C \, \tilde{\mathbb T}\) with the Kronecker approximation \(\tilde{\mathbb T}\) of a basis projection operator (basis_projection_operator()). The preconditioner then approximates

\[A = \mathbb L^T \mathbb M_{\textrm{mid}} \mathbb L + \sigma \, \mathbb S \,,\]

with mid (default: the mass operator of the codomain of \(\mathbb L\)) and stab (default: of its domain). The weights of mid and stab are approximated by separable shapes (separately, and per diagonal block with block_shapes), times the mean of each block; the off-diagonal blocks of mid are neglected. Each diagonal block of \(A\) is then a sum of Kronecker products \(\sum_t c_t F_{t,1} \otimes F_{t,2} \otimes F_{t,3} + \sigma_c M_1 \otimes M_2 \otimes M_3\) (block Jacobi in the components of the domain). It is inverted in the basis \(U_1 \otimes U_2 \otimes U_3\) of the generalized eigenproblems \(\hat S_d U_d = M_d U_d \Lambda_d\) of the stabilization \(M_d\) and a summary stiffness \(\hat S_d = \sum_t |c_t| F_{t,d} \prod_{e \neq d} \textrm{tr}(M_e^{-1} F_{t,e}) / n_e\) (over the symmetric terms), where every term is replaced by its diagonal in that basis. This is the diagonal of the Kronecker approximation of \(A\) in the eigenbasis, hence positive. It is exact if the eigenbasis diagonalizes all terms, e.g. for derivatives as above, or for circulant 1d factors (periodic directions with constant weights); otherwise, e.g. for the mixed terms of a field-aligned operator, it is an approximation. diagonal_scaling, kernel_correction and stab_average are not supported (the diagonal of the exact operator is not available, since basis projection operators contain inverse inter-/histopolation matrices).

With polar splines (mass_ops.derham.polar_splines), the constructor returns a PolarStiffnessPreconditioner instead (grad and curl only; diagonal_scaling and weights are ignored there, and its own options such as poloidal_solver can be passed as keyword arguments).

Preconditioner for the stabilized stiffness operators \(A = \mathbb d^T \mathbb M_{k+1} \mathbb d + \sigma \mathbb M_k\) (\(\mathbb d \in \{\mathbb G, \mathbb C\}\), see StiffnessPreconditioner) on polar spline spaces, exploiting the 2D x 1D Kronecker structure of the polar extraction (see struphy.polar.kron_2dx1d).

With the polar extraction \(\mathbb E\) (\(\mathbb E_{k+1}^T \mathbb d = \mathbb d_\textnormal{tp} \mathbb E_k^T\)), \(A = \mathbb E_k (\mathbb d_\textnormal{tp}^T \mathbb M^\textnormal{tp}_{k+1} \mathbb d_\textnormal{tp} + \sigma \mathbb M^\textnormal{tp}_k) \mathbb E_k^T\). The blocks of the tensor-product derivative \(\mathbb d_\textnormal{tp}\) differentiate either in the poloidal plane (identity in \(\eta_3\)) or in \(\eta_3\) (identity in the poloidal plane). With the weights of the mass matrices reduced in \(\eta_3\) (see reduced_weight_2d()), each group \(G\) of components (see component_groups()) is approximated by

\[A_G \approx \left(\mathbb K_\textnormal{pol} + \sigma \mathbb M_\textnormal{pol}\right) \otimes \mathbb M_3 + \mathbb W_\textnormal{pol} \otimes \mathbb S_3 \,,\]

where \(\mathbb K_\textnormal{pol}\) collects the terms with poloidal derivatives on both sides, \(\mathbb W_\textnormal{pol}\) those with \(\eta_3\) derivatives on both sides (\(\mathbb S_3 = \mathbb D_3^T \mathbb M^D_3 \mathbb D_3\)), and \(\mathbb M_\textnormal{pol}\) is the poloidal stabilization (all with the polar extraction applied). It is inverted by fast diagonalization in \(\eta_3\) and one poloidal solve per \(\eta_3\) mode (PolarKronSum2Dx1DSolver). Neglected are the mixed terms (poloidal derivative on one side, \(\eta_3\) derivative on the other), which vanish if the weights do not couple the poloidal plane and \(\eta_3\) (e.g. a cylinder or an axisymmetric torus without straight field line coordinates), and the couplings between the groups. For the gradient, the preconditioner is then the exact inverse of \(A\) for weights that do not depend on \(\eta_3\). For the curl, the groups \((E_1, E_2)\) and \(E_3\) are decoupled (block Jacobi) and, with kernel_correction, the correction \(\sigma^{-1} \mathbb G P_\textnormal{grad} \mathbb G^T\) on the kernel of the curl is added (see StiffnessPreconditioner). The identity stabilization (stab="Id") is approximated by its diagonal in the eigenbasis of the fast diagonalization.

For the gradient, stab_average replaces the stabilization \(\mathbb S\) by \(\mathbb S (\mathbb I - \Pi_{\mathbb S})\) (PolarWeightedAverageProjection, averages over \(\eta_2\) and/or \(\eta_3\)). With \(\mathbb S \approx \mathbb S_\textnormal{pol} \otimes \mathbb M_3\), the average over \(\eta_3\) gives the 1d factor \(F_3 = c_3 c_3^\top / (\mathbb 1^\top c_3)\), \(c_3 = \mathbb M_3 \mathbb 1\), which acts only on the constant mode of the fast diagonalization (exact for periodic \(\eta_3\)), and the average over \(\eta_2\) the low-rank poloidal factor \(\mathbb S_\textnormal{pol} \mathbb B (\mathbb B^\top \mathbb S_\textnormal{pol} \mathbb B)^{-1} \mathbb B^\top \mathbb S_\textnormal{pol}\), which is included in the poloidal solves by the Woodbury identity. With weights that do not depend on \(\eta_3\), the preconditioner thus stays exact (except for stab="Id", whose average is Euclidean).

The divergence is not implemented yet.

Auxiliary space preconditioner of Hiptmair and Xu (SIAM J. Numer. Anal. 45, 2007) for the curl-curl operator

\[A = \mathbb C^T \mathbb M_2 \mathbb C + \sigma \, \mathbb M_1 \,, \qquad \sigma > 0\,.\]

The kernel of the curl (the gradients) and the smooth fields are not reduced by point or block smoothers. They are corrected in the auxiliary spaces \(V^0_h\) (scalar potentials) and \((V^0_h)^3\) (vector-valued \(H^1\) splines, "H1vec"):

\[P = S + \sigma^{-1} \, \mathbb G \, P_0 \, \mathbb G^T + \Pi \, P_v \, \Pi^T \,,\]

where

  • \(S\) is the smoother, either the Jacobi preconditioner \(\textrm{diag}(A)^{-1}\) ("jacobi") or the block Jacobi part of StiffnessPreconditioner ("block_jacobi", default, fast diagonalization of the diagonal blocks of \(A\)),

  • \(P_0\) approximates the inverse of \(\mathbb G^T \mathbb M_1 \mathbb G\) (StiffnessPreconditioner for the gradient with mid=stab), since \(A \mathbb G = \sigma \mathbb M_1 \mathbb G\),

  • \(\Pi: (V^0_h)^3 \to V^1_h\) is the commuting projector \(\hat \Pi^1\) applied to vector-valued \(H^1\) splines (BasisProjectionOperator with identity weight),

  • \(P_v\) approximates the inverse of the vector Laplacian \(\nabla^T \nabla + \sigma\) on \((V^0_h)^3\), which bounds \(\Pi^T A \Pi\) from above: the scalar StiffnessPreconditioner for the gradient with coefficient \(\sigma\), applied to each component.

With essential boundary conditions, all components of the auxiliary space \((V^0_h)^3\) vanish on the Dirichlet boundary, which is the stable regular decomposition \(H_0(\textnormal{curl}) = H^1_0(\Omega)^3 + \nabla H^1_0(\Omega)\). The number of PCG iterations is then bounded independently of the mesh size and of \(\sigma\).

Polar splines are not supported (as for StiffnessPreconditioner).

Polar 2D x 1D Kronecker solvers used by the polar preconditioners:

2D x 1D Kronecker structure of linear operators on polar spline spaces.

Polar extraction operators only act in the poloidal plane \((\eta_1, \eta_2)\) and are the identity in \(\eta_3\). Inter-/histopolation matrices of the commuting projectors and (axisymmetric) weighted mass matrices thus have the structure

\[\mathbb A = \bigoplus_G \mathbb A^G_\textnormal{pol} \otimes \mathbb A^G_3 \,,\]

where the direct sum runs over groups \(G\) of vector components (components which share the same spline basis in \(\eta_3\) and are coupled at the pole), \(\mathbb A^G_\textnormal{pol}\) is a sparse matrix acting on the polar unknowns of the poloidal plane (polar coefficients and tensor-product rings \(i \geq\) n_rings) and \(\mathbb A^G_3\) is a 1d (banded) matrix.

The inverse \((\mathbb A_\textnormal{pol} \otimes \mathbb A_3)^{-1} = (\mathbb A_\textnormal{pol}^{-1} \otimes I)(I \otimes \mathbb A_3^{-1})\) is applied in two steps: a 1d solve along \(\eta_3\) and a (batched) 2d solve in the poloidal plane. For the latter, the following solvers are available (see make_poloidal_solver()):

  • "lu": sparse LU factorization (exact),

  • "ilu": incomplete LU factorization (approximate inverse),

  • "schur": block elimination of the pole block (polar coefficients and first tensor-product ring), with a dense LU of the small Schur complement and an exact (Kronecker or sparse LU) or incomplete (ILU) solve of the outer block.

In parallel runs, the data is redistributed with MPI_Alltoallv: along \(\eta_3\) within the sub-communicator of processes sharing the same poloidal sub-domain, and in the poloidal plane within the sub-communicator of processes sharing the same \(\eta_3\) sub-domain.

\[\begin{split}x &= S^{-1} \, (b_x - B b_y ) \,, \\ y &= b_y - C x \,.\end{split}\]
Parameters:

  • M (BlockLinearOperator) – Block matrix \([[A, B], [C, \mathbb I]]\).

It needs two products with \(P\) per iteration ("pbicgstab" three), with the same stopping criterion (residual of \(S x\)).
